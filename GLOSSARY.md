# Индексатор судебных дел

Собирает сохранённые версии карточек дел из архива сборщика (courts) и МГС в один поисковый документ на дело и пишет его в Elasticsearch. Термины, общие с courts, совпадают с его `GLOSSARY.md`.

## Language

### Дела

**Дело**:
Судебное дело; в индексе ему соответствует ровно один документ индекса.
_Avoid_: кейс, case (в прозе)

**ID дела**:
`{суд}_{дата регистрации}_{краткий номер}` — ключ документа индекса; детерминированная функция данных дела, не порядка индексации.
_Avoid_: id_final, _id (в прозе)

**Формульный id**:
ID дела, вычисленный формулой из номера, даты регистрации и суда одной записи.

**Первый выданный номер**:
Номер, который карточка получила первой; именно он входит в ID дела, даже если карточка потом сменила номер.

**UID карточки**:
Неизменный идентификатор карточки на sudrf; один UID — одна карточка, но не одно производство (у жалоб одного производства разные UID).
_Avoid_: uuid (в прозе), case_uid

**Правило группы**:
Выбор ID дела для всех сохранений с одним UID карточки: побеждает самая ранняя дата регистрации.

**Близнец**:
Документ индекса того же дела под другим ID дела; при индексации вливается в целевой документ и удаляется.
_Avoid_: дубль (если не доказано, что это то же дело)

**Карточка**:
Страница дела на сайте суда: участники, судья, движение, акт.
_Avoid_: страница дела, case page

**Судебный акт**:
Текст решения или приговора из карточки; одинаковый текст — один акт, сколько бы раз его ни сохранили.
_Avoid_: решение (когда речь о документе), документ

**Тип дела**:
Одно из: УК, ГК, КАС, КоАП, Материал.

**Инстанция**:
Первая, апелляционная или кассационная — уровень суда, в котором рассматривается дело.

**Движение дела**:
Таблица заседаний и процессуальных событий в карточке.

**Скрытое дело**:
Дело МГС, которое открытые данные помечают скрытым уже после того, как мы его проиндексировали; ссылка, акты и движение в документе индекса сохраняются.

### Источники

**Сохранение**:
Одна сохранённая сборщиком версия карточки — то, из чего индексатор собирает документ.
_Avoid_: скачивание, загрузка

**Архив**:
Все сохранения карточек, записанные сборщиком.
_Avoid_: дамп, хранилище

**МГС**:
Мосгорсуд и его районные суды (mos-gorsud.ru): отдельная платформа со своим ключом дела, вне формулы и правила группы.

### Индексация

**Документ индекса**:
Поисковый документ дела в ES: все его сохранения и акты, слитые в один.
_Avoid_: документ (без уточнения — путается с судебным актом)

**Перекачка**:
Заявка сборщику сохранить дело заново, потому что его сохранение нельзя проиндексировать.
_Avoid_: ретрай, redownload (в прозе)

**Приоритетная индексация**:
Отдельный частый проход только по сохранениям отслеживаемых карточек, чтобы они попали в поиск за минуты.
